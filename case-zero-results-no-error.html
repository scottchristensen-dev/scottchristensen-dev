Zero results, no error

A silent failure caught during a live phone test — plus more triage from the same project.

Project: Hermes · built with Claude under my direction

← All projects

The problem

During a live test on my phone, a scanner returned zero results with no error or warning.

What I found

Two functions had the same name. The second one quietly replaced the first, so the scanner ran the wrong code and returned nothing.

The fix

Removed the duplicate and re-ran the scan: 81 results, confirmed on the phone.

More triage from the same project

  • 17 security-scan alerts: reviewed every one, confirmed all were harmless test data, and kept the check at full strength instead of weakening it.
  • “It loads and nothing happens”: the tool worked but gave no feedback. Added visible results and per-source counts.
  • 5 failing tests: fixed 4, confirmed 2 were intended changes before updating them, and found a real access bug — partners couldn't load scripts their pages needed.
  • Image finder: wrong matches went from 13 of 15 to 0 of 30 after I found it was mistaking wiki pages for image files.

Takeaway

The absence of an error does not confirm that something works, so I test on the real device, as the user will.
