Night Shift

Unattended overnight build automation: each project resumes from its last written handoff, the next module is built and tested, and a morning report is prepared for review.

Part of Hermes · Built with Claude under my direction · Python, systemd timers

← All projects

How a night works

  • Each project ends its day with a written handoff that names the next module and how to check it.
  • In a fixed night window, a systemd timer starts the queued runs — up to 10 a night — each building one small module and running its tests.
  • A second, lower-cost model independently reviews each run.
  • Each morning: a report of completed work, failures and pending decisions, delivered to my phone.

Guard rails

  • A nightly spending cap.
  • Cleanup is propose-only — nothing is archived or closed until I approve the batch.
  • Merges require my approval; resolved questions are not raised again.
  • Lessons from each run are recorded so later runs avoid the same errors.
