App Ladder

A series of utilities built for Linux, Windows and Android, each more complex than the last.

Built with Claude under my direction · Linux, Windows, Android

← All projects

The rungs

  • Pulse — a health light showing whether my home server is OK.
  • Drop — send a file from any device to my server, with one revocable token per device.
  • Tally — shared lists, synced through one shared sync service that every future app reuses.
  • Bell — push notifications to every device without Google's push service, silent by default (in progress).

Why it's built this way

Each rung adds one new skill — status checks, secure upload, sync, push — and the next rung reuses it instead of rebuilding it.
