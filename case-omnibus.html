Omnibus

An Android audiobook player that syncs my library, place and history through my own home server — no cloud account.

Built with Claude under my direction · Kotlin, Python, SQLite, systemd, Ollama

← All projects

Features that matter

  • Player: per-book speed and voice EQ presets, sleep timer, smart rewind, bookmarks, Android Auto, home-screen widget.
  • Library: sort by author, title or date added; full series support with reading order and gaps.
  • Library health: checks every book on import for missing, corrupt or short files; finds duplicates and keeps the better copy; deleted books sit in a 30-day trash first.
  • Read-along and Story help: the server transcribes books overnight, and the phone can answer “what did I miss?” and “who's who?” — without spoilers past my spot.
  • Sync server: private-network only, a separate token for each device, nightly backups kept for 14 days.

A real problem it solved

Read-aloud and transcripts mangled the character names in a translated novel. I chose a per-book name list that fixes both the text and how names are spoken — 904 lines corrected in one pass.

Built to feel fast

Story help answers for my most-listened books are prepared ahead by a systemd timer every 3 hours, so the phone gets them with zero AI calls at the moment I ask. Uploads resume after a dropped connection and never repeat work.
