Atlas

A disk-space map and file manager for Linux, Windows and Android — see what fills a drive, then clean it up safely.

Built on Hermes · Built with Claude under my direction · Kotlin, Compose Multiplatform

← All projects

What it does

  • Folder sizes and a treemap of the whole drive, with file previews.
  • Move, rename and delete — deletes go to the Trash first, and protected system folders are left alone.
  • 🧬 Duplicates: finds identical files and the same song saved in two places, suggests which copy to keep (most complete first, then quality, cover art and tags), and copies any missing files into the keeper before the rest go to the Trash.
  • Every duplicate group is labelled ✅ Safe, 🟡 Check first or ⚠ Copy first, so it's clear what is safe to remove.

Release and testing

  • One codebase, three platforms: a Linux package, an Android app and a Windows installer.
  • 44 engine tests passing; Windows builds are tested in a virtual machine before release.
  • Touch-tested on an Android emulator and approved on a real phone.
