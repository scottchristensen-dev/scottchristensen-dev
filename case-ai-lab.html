AI Lab

My multi-model workshop: give one task to several AI models, compare their work side by side, and build software and art with them under a hard spending cap.

Works with Hermes · Built with Claude under my direction · Python (standard library only), JavaScript

← All projects

What it does

  • ⚖️ Compare: 2–4 models get the same task, each in its own sandboxed copy of the project with no network, then I see time, cost, tokens, steps and checks passed side by side.
  • 🤖 Agent loop: plan → write → run → check, with a live preview of the result.
  • 🎨 Pictures and short video made on my own graphics card with open models — $0 per picture and nothing leaves my server.
  • 📋 Review: finished work goes to a review list; nothing reaches my main system until I approve it.

Cost and privacy rules, enforced in code

  • A daily spending cap ($2 by default) and a $0.50 cap per comparison. Every call is estimated high before it runs, and refused if it would cross the cap.
  • Projects marked sensitive can only use models running on my own machine.
  • Hosted model calls ask for zero data retention and providers that don't train on prompts.
  • When connected to Hermes, Hermes holds the API keys and the budget — the Lab never sees a key.

It can improve itself — safely

The Lab can propose changes to its own code, but a separate guard it can't touch keeps the last 30 working copies, and every self-change waits for my approval before it goes live.

By the numbers

  • 215 version-controlled changes since 20 Nov 2026.
  • 61 automated test files.
  • Runs standalone or connected to Hermes.
